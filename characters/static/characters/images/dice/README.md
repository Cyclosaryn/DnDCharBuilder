# Dice Icons Setup

## Required Icons from Flaticon

You need to download black and white dice icons from Flaticon and place them in this folder.

### Icons Needed:
1. **d4.png** - Four-sided die (tetrahedron/pyramid)
2. **d6.png** - Six-sided die (standard cube die)
3. **d8.png** - Eight-sided die (octahedron)
4. **d10.png** - Ten-sided die
5. **d12.png** - Twelve-sided die (dodecahedron)
6. **d20.png** - Twenty-sided die (icosahedron)

### How to Download:

1. Go to https://www.flaticon.com
2. Search for "dice d4", "dice d6", "dice d8", etc.
3. Download **black and white** or **monochrome** versions
4. Save each icon with the correct filename (d4.png, d6.png, etc.)
5. Place all icons in this folder

### Recommended Search Terms:
- "polyhedral dice"
- "d4 dice black"
- "d6 dice icon"
- "d8 dice"
- "d10 dice"
- "d12 dice"  
- "d20 dice"
- "rpg dice"
- "tabletop dice"

### Icon Specifications:
- **Format**: PNG with transparent background
- **Color**: Black icon (will be inverted to white on dark buttons)
- **Size**: At least 128x128px (higher resolution is better)
- **Style**: Simple, clean, recognizable silhouette
